This repository contains the Magma code supporting the paper "Primitive points on some low degree Fermat curves" by Maleeha Khawaja.

* The file C6.m contains the code supporting the computation of the rational points on the hyperelliptic curve $C_6$.
* The file C8.m contains the code supporting the computation of the rational points on the hyperelliptic curve $C_8$.
* The files F8.m support the proof of Theorem 2.
